# Changelog

All notable changes to Ooh will be documented here. Releases follow [Semantic Versioning](https://semver.org/).

## Unreleased

### Added

- Local task and parallel-path management using standard Git worktrees.
- Immutable checkpoints with structured handoffs, evidence artifacts, and review comments.
- Embedded summary-first diff dashboard with light and dark modes.
- Isolated single-commit integration candidates, conflict workspaces, preflight checks, and safe undo.
- Stable JSON CLI responses and a portable Agent Skill.
- Local archive retention, diagnostics, signed release configuration, and Homebrew publishing.
